# 贡献职责与依赖边界

本贡献在当前 master 的已有能力之上增加原生设施、布局、公共交通查询、正常预览和可靠控制。公开接口以正常资金、内容资格、原生校验与可核验的失败结果为约束；本机城市、实体编号、私人启动脚本和施工记录不属于仓库内容。

当前0.9.1基于官方72bd7e0，继承已经合入的[HTTP安全贡献#3](https://github.com/LancerComet/cities-skylines-2-mcp/pull/3)；它已成为基准，不再作为未合入功能排除。仍与[专门建造及市辖区贡献#4](https://github.com/LancerComet/cities-skylines-2-mcp/pull/4)按功能分工，不能按文件名删除共享实现。

| 职责 | 本贡献边界 | 保留的依赖或基准行为 |
|---|---|---|
| Host/Origin、认证token、通用变更POST策略 | 继承官方#3，通过已有共享客户端适配本贡献路径；不是独立重做#3 | 严格HTTP framing、UTF-8、loopback限制、保存超时与未知应用；公开弹窗操作同受POST约束 |
| 网格建造、任意道路替换、航空线路创建、施工 watchdog | 不增加这些入口，也不抢回玩家当前工具 | master 已有道路替换、连接、路网、交叉口和车型入口；失去工具所有权时结束本贡献拥有的请求 |
| 与PR4重复的总量产消／资源格查询、专门产业创建／边界编辑 | 不增加重复接口；通用放置拒绝产业占位体 | 保我们独有的加工配方／岗位汇总、采掘模型校准和母体作业线完整关系等有界只读诊断，不按“产业”关键词整体删除 |
| 工业资源分项税 | 不增加读写分支 | master 工业综合税率，以及本贡献住宅学历、商业/办公产品分项税 |
| 市辖区详情、重塑、改名、删除 | 不增加接口；通用改名拒绝市辖区 | master 市辖区创建/政策，以及公共设施服务范围分配 |
| CLI城市控制 | 显式上下文/加载GUID、主档名、记录隔离、整批schema和失败前缀；watch仅只读 | 正常手动工具写入；私人经营阈值与自动预算/暂停不进入公共CLI |
| 生命周期与错误契约 | 关闭后不再入队，未开始请求有明确阶段证明；保存纹理及控制点按资源所有权释放 | 已开始异步操作拥有自己的结果，未知应用不自动重放，原生作业借用数据不错误释放 |


继续不引入#4的产业/资源产消及专门边界编辑、工业资源税、市辖区编辑、航空线路创建、grid/net-replace或强制夺回玩家工具的watchdog；公共CLI保持只读watch和显式主档名。通用布局只允许正常原生预览/Validation，不按名字导入另一PR的工具或实现。任意网络替换重叠的replaceRoads参数在公开SDK和原生HTTP白名单中都被排除，负例验证为零请求；本地完整生产版保留，不能反向以贡献版覆盖生产。

基础版已包含的功能保持兼容。某个早期 PR 的历史描述包含一个功能，不代表该功能仍是其未合并增量；审查应比较当前 master、实际 diff 和调用方。后续生产改进进入公开贡献前，也需重新检查接口职责、依赖、正常建造前提、版本门、数据所有权与失败语义。

验证包含完整桥接构建、真实 SDK stdio 契约、HTTP/内存门槛/启动模式的离线诊断。测试使用合成数据，不模拟原生城市、车辆运营、作业调度或 GPU 保存管线；公开构建默认不部署。这些检查不证明游戏内全部场景已通过，也不证明持续内存增长的根因已经解决。

按当前PR4实际源码逐项比对：其Production模块仅有GetProduction／GetNaturalResources，SpecializedArea模块负责列出／创建／重塑区域。加工配方与岗位汇总、采掘模型校准、母体作业线声明及全路径关联是本贡献独有的有界只读诊断，0.9.1保留这三项，不按领域名删除。

当前产品版本统一为 **0.9.1**，原生控制协议由/ping的 **controlApiVersion: 1** 标识，普通修复使用Git提交追踪。无协议字段的历史发行版仍按原最低版本检查；明确未知的协议不能因产品数字很大而放行。新旧版本兼容与产品发布节奏分别维护。

已清障损毁Attached经营Hub的正常原位重建要求当前Loaded GUID、完整母体/Hub双向关系、自有Lot及正常资格。PR4负责产业创建/列出/重塑，未实现该重建入口；本贡献继续保留独有修复。地下输电选择真实原生地下变体并保留固定节点深度，正常原生预览/Validation/费用保持。后台场景帧默认关闭，保原生屏障和资源所有权；公共30/90、未标记启动保玩家设置、只读watch与显式主档名不变。
