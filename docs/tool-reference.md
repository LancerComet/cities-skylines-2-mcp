# 完整工具目录

桥接与 MCP 公共版本：0.10.2；共 121 个工具。

本目录从实际 MCP listTools 握手生成。参数以工具 schema 为准；正常资格、预览、失败恢复和运营验收见 [原生控制与验收](native-control.md)。
