# 请求内道路纵断面（0.10.5）

`cs2_build_road_layout(preserveVerticalProfile=true)`保留请求明确指定的三维曲线纵断面。默认不启用，既有布局行为不变。只用于已设计并核验的正常可见道路，不提供force或错误忽略。

当前原生`CourseSplitSystem`在PostTool按地形重采样、拟合中间高度；输入曲线坡度合格不证明生成曲线合格。当前正常等坡模组在Modification1修改`NetCourse`，本功能采用同一时段，在`GenerateNodes`、正常Validation和费用计算之前恢复本次定义的y。没有修改游戏或第三方DLL，也没有伪造Owner。

每次请求有独立随机种子区间，每个输入段保留4096个原生拆分序号。仅种子区间、预制体和精确XZ子曲线三者都相符时恢复y；只修改本次临时定义，不改现场永久网络。未知Owner、平面偏差超过5厘米、既有节点高度差超过10厘米、缺少任何输入段或超出当前原生高程范围时整次拒绝。曲线采样水平步长上界4米。原生拓扑、错误、安全标记、解锁、用地、碰撞和计费继续执行；返回`verticalProfile`审计。

原生拆分仍按正常生成阶段执行，保留纵断面不证明连接、净空或工程坡度。先`dryRun=true`核原生错误、实际生成曲线和影响对象；只有全部正常通过再显式应用。实建后分别回读曲线、节点、车道、原有网络及运营。不能以`allowed=true`代替这些验收。

不支持把输入曲线移动到既有节点之外，无法映射时须重新设计。后处理只允许基础预制体自己的高程范围，某些仅地下变体放宽的场景会保守拒绝。种子仅限一次活动工具请求，不跨加载持有实体或形成保存数据。

公共0.10.5同步SDK与原生HTTP字段白名单，并以链接真实C#规则的正反例验证。布局替换参数不在此贡献范围，未知字段拒绝。显式保留纵断面还要求共享节点各端点相对均值1厘米内一致，避免不同高度使用同一节点编号。
